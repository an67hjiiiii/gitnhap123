This directory contains the generated OpenAPI snapshot for the `/api/review` API, captured as v0 for FE/BE review.

From `backend/`, regenerate it with:

```powershell
& 'D:\CAP1_AI_STUDIO_C1SE27\backend\.venv\Scripts\python.exe' scripts/export_review_openapi.py
```

Breaking changes require approval from both FE and BE before updating the snapshot.
